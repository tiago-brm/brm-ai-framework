# Modelo de política

Copie para `politicas/` e preencha. O cabeçalho abaixo é obrigatório.

```yaml
---
tipo: politica
zona: politicas
area: geral          # fiscal, saude, trabalhista ou juridica exigem revisor nomeado
skills: [nome_da_skill]   # skills que esta política documenta (mapa de cobertura)
fonte: onde a regra vem (contrato, lei, decisão da diretoria)
revisado_por: nome de quem conferiu
revisado_em: 2026-10-09
---
```

Escreva a regra em texto. Ela é conhecimento: não muda o comportamento do sistema por si só.
